# Pawl

VS Code extension: on-demand AI completion with a 0–5 help dial, triggered only by a go key. Models via OpenRouter (BYOK).

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `pranavpage/pawl-vscode`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
